# SaaS Ideas — Knowledge System

This is the canonical documentation for the `saas-ideas` repository. The
committed Markdown here is the source of truth; the published sortable catalog
at <https://ideas.sassmaker.com/> is a generated artifact built from
`scripts/build.py`.

> New here? Read
> [AGENTS.md](https://github.com/sass-maker/saas-ideas/blob/main/AGENTS.md)
> first (repository bootloader), then
> [Product overview](product/overview.md).

## What this repo is

A scored, sortable catalog of SaaS product ideas, filtered to tech-heavy,
solo-feasible bets. Each idea is scored on Fun / Money / Tech / Competition
(/10) plus a solo-dev Feasibility axis and a customer type, then collapsed into
`fun` and `money` derived scores and a `best_bet` flag. The output is a static
sortable HTML table deployed to Cloudflare Pages.
